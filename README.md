# MEMENTO - 余命三十日

ブラウザで遊べる、1ファイル構成の短編ローグライト RPG。

## 起動

`index.html` をブラウザで開けばプレイできます。

ローカルサーバーで確認する場合:

```sh
python3 -m http.server 8123
```

その後 `http://localhost:8123/` を開きます。

## 現在入っている要素

- Day 1-30 の進行と分岐イベント
- 道中の通常敵はフィールド上で斬って倒すリアルタイム戦闘
- 各階の影をすべて祓るまで階段は封印される
- 武器ごとの攻撃範囲、ノックバック、鈍化、回避、回復
- ボス/重要戦では既存のコマンド戦闘を使用
- 年齢成長、武器、状態異常、消耗アイテム
- 記憶メニューから道中アイテム使用と装備変更
- 隠しルート、中ボス、真エンド、称号記録
- スマホ向け D パッドとスワイプ操作

## 再開メモ

- 最新版は `index.html`。`memento.html` は古いスナップショット。
- タイトルは「余命三十日」だが、現在の開始余命はバランス調整で `45日` になっている。
- 方向性は、GBA時代のゼルダのように、通常敵をリアルタイムでさばきながら塔を進む形。
- いまの完成版初稿では「通常階はアクション」「ボス/重要戦はコマンド戦闘」のハイブリッド。
- 次にフィードバックを見るなら、敵の移動速度、階ごとの敵数、武器火力、階段封印の重さを重点的に調整する。
- その次はイベントやエンディングの到達条件をデバッグ用に可視化できる開発モードがあると調整が速くなる。
